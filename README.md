## ✨ Features  

- 🔐 Secure Authentication using JWT  
- 🧾 Invoice CRUD (Create, Read, Update, Delete)  
- 📄 Download invoices as PDF  
- 📧 Email invoice support (Nodemailer)  
- 🔍 Search and filter invoices  
- 📊 Dashboard for managing invoices  
- 📱 Fully responsive UI  
- ⚡ RESTful API integration  

---

## 🛠 Tech Stack  

### 🎨 Frontend  
- React.js  
- Axios  
- React Router DOM  
- jsPDF & jsPDF-Autotable  
- CSS / React Icons  

### ⚙️ Backend  
- Node.js  
- Express.js  
- MongoDB & Mongoose  
- JWT Authentication  
- Nodemailer  
- Validator
